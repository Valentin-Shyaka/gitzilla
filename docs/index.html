gitzilla

Know within a minute when a push to your GitHub repos didn't come from your Mac.

Every push you make carries a note signed by a Secure Enclave key. A push that arrives at GitHub without one sets off an alert on your phone, and one confirmation rewinds the branches from local mirrors.

git clone https://github.com/Valentin-Shyaka/gitzilla && cd gitzilla && ./install.sh

Why

On 3 Oct 2026 a stolen GitHub credential force-pushed the PolinRider malware into 67 branches and tags across 13 repositories, while the owner's laptop was asleep.

GitHub accepted every push: each one was made as the account owner. Push events name the account, never the token or key that made the push, and personal accounts have no API to ask. So gitzilla makes your own Mac vouch for every push it makes, and treats anything it didn't vouch for as hostile.

How it works

your mac  pre-push hook ── scan ── sign note ──┐
                                           ├──▶ your worker ── match? ──▶ silent
github    read-only app ── push webhook ──┘                  └─ no ──▶ phone alert
pre-push hook

Scans the pushed commits for known payloads and blocks them. Signs repo, ref, old, new, time, nonce with an Enclave key that never leaves the chip.

worker

Your own Cloudflare Worker (free plan). Matches notes against GitHub's push events and sends alerts to ntfy and, optionally, Slack.

github app

Private to your account, read-only: Contents and Metadata. Reports pushes and its own removal.

agent

every 5 min. Keeps bare mirrors of every repo and deep-checks suspicious pushes.

restore

on red. Rewinds affected branches to the last signed commit, after you confirm.

reconcile

hourly. Catches missed webhooks and new SSH or signing keys on your account.

rotate

daily check. Walks you through a new gh token and SSH key every 5 days.

Alerts

silent

The push has a valid note from your Mac. That's every normal push.

orange

One push without a note. Often you, with --no-verify or another machine.

red

Force-push without a note, a burst across repos, unsigned commits, a known payload, a new key on your account, or the app being removed.

Alerts carry repo, ref, SHAs and flags. Never commit content.

Security model

Nothing it stores can push code.

push-note key

Secure Enclave. Can't be exported.

login key

Secure Enclave, Touch ID per use.

app private key

not kept. Deleted right after install.

cloudflare login

not kept. Logged out after each deploy.

gh token

Can't push. Expires in 7 days, rotated every 5.

worker secrets

Could send fake alerts or read alert text. Can't touch code.

Install

Requires macOS, Secretive, gh, node, jq, a free Cloudflare account and the ntfy app. Slack is optional. Everything runs on your own accounts.

# 1. tools
$ brew install gh node jq && gh auth login

# 2. GitHub SSH key + commit signing in Secretive (see README)

# 3. guided install: worker, github app, hook, mirrors, launchd
$ git clone https://github.com/Valentin-Shyaka/gitzilla
$ cd gitzilla && ./install.sh

# resume or redo a step
$ ./install.sh --from-step hook

Limits

  • It can't stop a push before GitHub accepts it. It tells you fast and helps you undo it.
  • If your Worker is unreachable, pushes still go through and show up as orange.
  • Events are kept for 7 days. A Mac offline for longer gets a "lost events" alert.
  • macOS and Secretive only.
  • Repos with their own hooks path (husky, lefthook) need a one-line change.
